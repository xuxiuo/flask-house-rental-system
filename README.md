# 智能租房系统（Flask + MySQL 课程设计项目）

## 项目介绍

本项目是基于 **Flask 框架 + MySQL + SQLAlchemy ORM** 开发的智能租房 Web 平台，采用**蓝图模块化**开发架构，将项目拆分为首页、列表页、房源详情页、用户中心四大独立业务模块。

项目整合 **ECharts 数据可视化、线性回归房价预测、皮尔逊协同过滤推荐算法**，实现房源展示、多条件搜索、分页浏览、房源评分、收藏管理、浏览记录、智能推荐、房价走势预测等完整功能。

前后端采用模板渲染 + AJAX 异步交互，通过 Cookie 保持登录状态，MySQL 持久化存储房源、用户、评分及浏览推荐数据，是一套功能完整、结构规范、适合课程设计与实训的 Python Web 实战项目。

## 技术栈

### 后端

- Python Flask / Flask 蓝图
- Flask-SQLAlchemy ORM
- MySQL 数据库
- 线性回归、皮尔逊相关系数算法
- pymysql 数据库驱动

### 前端

- HTML / 模板页面
- Jinja2 自定义过滤器
- JavaScript 原生交互
- ECharts 数据可视化
- Cookie 本地存储

## 项目目录结构

```
├── app.py              # 项目入口、蓝图注册、数据库初始化
├── settings.py         # 项目配置、数据库连接配置
├── models.py           # 数据库模型类定义
├── index_page.py       # 首页业务逻辑
├── list_page.py        # 房源列表页逻辑
├── detail_page.py      # 房源详情页、图表接口
├── user.py             # 用户中心逻辑
├── static              # 静态资源(css/js/图片)
├── templates           # 所有HTML模板页面
└── utils               # 算法工具类
```

## 数据库表设计

项目共设计 4 张数据表：

1. `house_info`     房源信息表
2. `user_info`     用户信息表
3. `house_recommend` 浏览推荐记录表
4. `house_rating`   房源评分记录表

## 基础核心功能

1. 首页房源总数展示、最新房源、最热房源推荐
2. 地区 / 户型关键字模糊搜索、下拉智能提示
3. 房源列表分页展示，按发布时间 / 浏览量 / 价格排序
4. 自定义模板过滤器：标题省略、空数据默认提示
5. 房源详情信息展示、浏览量自动累加
6. ECharts 多图表可视化：饼图 / 柱状图 / 折线图 / 散点房价预测
7. 基于皮尔逊算法实现个性化房源推荐
8. 用户注册、登录、退出、Cookie 保持登录
9. 个人信息修改、房源收藏、浏览记录查看与清空
10. 房源评分、分数校验、平均分实时统计

## 运行步骤

1. 本地创建 MySQL 数据库 `house`
2. 导入项目对应 SQL 数据表
3. 修改 `settings.py` 数据库账号密码为本地配置
4. 安装依赖

```
pip install flask flask-sqlalchemy pymysql scikit-learn
```

1. 运行 `app.py`，访问 `http://127.0.0.1:5000`

## 项目特点

- 采用蓝图模块化，代码解耦、结构清晰易维护
- 使用 ORM 操作数据库，无需手写原生 SQL
- 集成多种 ECharts 图表，实现房源数据分析
- 融入机器学习算法，实现房价预测与智能推荐
- 完善登录权限、数据校验、分页、过滤器等 Web 常用功能
- 代码规范，可直接用于 Python Web 课程设计、实验提交
